# ViaSegura – Portal educativo de prevenção de sinistros no trânsito

Projeto da disciplina Introdução ao Desenvolvimento Web (UFFS) · ODS 3, Meta 3.6.

## Estrutura
- `index.html`, `riscos.html`, `guia.html`, `quiz.html`, `sobre.html`
- `css/style.css` · `js/main.js` · `assets/img/`

## Paleta de cores
| Uso | Cor |
|---|---|
| Primária (cabeçalho, botões) | `#1F6F8B` |
| Destaque (bordas, progresso) | `#4296B2` |
| Fundo | `#E6ECF0` |
| Superfície (cartões) | `#FFFFFF` |
| Texto | `#14212B` |
| Rodapé | `#D9D9D9` |
| Tema escuro: fundo / primária | `#0F1A22` / `#6BB8D4` |

**Justificativa:** o azul-petróleo, derivado do wireframe, transmite calma e confiança, adequado a um tema de saúde e segurança. Foi escurecido de `#4296B2` para `#1F6F8B` para que o texto branco tenha contraste de cerca de 5,7:1 (acima do mínimo WCAG AA de 4,5:1). Fundos claros e cartões brancos garantem leitura direta, como no GOV.BR.

## Funcionalidades
Menu responsivo, filtro de dicas por perfil, quiz com pontuação e explicações, simulador de frenagem, tema claro/escuro, HTML semântico e recursos de acessibilidade (skip link, foco visível, aria, contraste).

## Como executar
Abra `index.html` no navegador.
